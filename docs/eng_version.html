Core principle

Upload data→ Detect file type→ Raw QC→ Clean / filter→ Data Quality Gate→ Application analysis→ Report / export

The agent should not jump directly from raw data to downstream analysis. A rigorous workflow should inspect the input data, perform raw quality control, clean or filter data when needed, run a post-cleaning quality gate, and then proceed to peptide, ancient-DNA, or microbiome applications.

Key rule: raw data → QC → cleaning/filtering → post-cleaning quality gate → downstream analysis.
2

How to start

Steps

  1. Open the project folder 2026summerproject in VS Code.
  2. Run the command below in the VS Code Terminal.
  3. Open the local web page printed by the terminal. By default, the app opens the browser automatically.
  4. Upload files, enter a natural-language request, and generate a workflow.
  5. Review the workflow, select an output folder, approve local execution, and run it.

VS Code Terminal commands

First-time setup:

cd /Users/tianaoliu/Documents/vscode/2026summerproject
python3 -m venv .venv
.venv/bin/python -m pip install -e '.[dev]'
.venv/bin/research-agent

Later launches after the environment has already been installed:

cd /Users/tianaoliu/Documents/vscode/2026summerproject
.venv/bin/research-agent

Fixed port without automatically opening a browser:

cd /Users/tianaoliu/Documents/vscode/2026summerproject
.venv/bin/research-agent --no-browser --port 8000
If the page opens but workflow generation fails, check the API key, model configuration, and network. If the workflow is generated but execution fails, check whether the required local tools are installed.

Environment and tools

Troubleshooting

ProblemLikely causeFix
A tool is reported as missingThe tool is not on PATH or its conda environment is not configured.Check conda env list and config/tool_envs.json.
Workflow generation failsAPI key, model configuration, or network issue.Check the API configuration and retry with a simpler request.
The workflow skips QCThe user requested a narrow single-tool action.For full analysis, explicitly ask for QC, post-cleaning quality check, and downstream analysis.
Data Quality Gate reports warningsPossible empty sequences, duplicates, invalid characters, malformed FASTQ records, or paired-read mismatch.Inspect data_quality_gate_report.json before continuing.
