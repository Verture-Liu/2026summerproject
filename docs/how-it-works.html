HOW PALEORIGOR WORKS

A research agent that shows its plan, stays inside its limits and keeps the evidence.

You describe an analysis in plain language. A language model drafts the workflow; the app checks it, you approve it, and skills on your own computer run it. Every run leaves a folder you can audit later.

Step through an example Install the app

ACGT In the background, bases next to a fragment break turn C→T and G→A, the damage pattern of ancient DNA.

Agent
The model turns your request into an explicit, ordered workflow. It plans only; it never touches your files.
Constraint
A validator checks every file reference, format and step dependency. Only registered skills can run, and requests that cross a stated limit are refused with a reason code.
Reproducibility
Final outputs, intermediate files, the report and SHA-256 checksums are kept together, so each run can be checked without calling the model again.

    HOW TO USE IT

    Five steps in the desktop app.

    The steps match the progress bar at the top of the app. Button names are shown as they appear on screen.

    1. 1

      Model API

      Enter the Base URL, Model and API Key of an OpenAI-compatible provider, then press Save Configuration and Test Connection. The key is stored in macOS Keychain (Windows Credential Manager on Windows) and is never shown again.

      Base URLhttps://api.example.com/v1 API Key•••••••••••• Save Configuration
    2. 2

      Upload files

      Describe the task in one or two sentences and add your files (FASTQ, FASTA, CSV, TSV and others), then press Create Task and Upload. The app inspects each file locally and records its format and SHA-256 checksum.

      lib01_R1.fastq.gz fastq lib01_R2.fastq.gz fastq Create Task and Upload
    3. 3

      Plan workflow

      Press Generate Workflow. The model receives your request and a summary of each file (name, format, size, column names, record count), not the file contents. You get back either a validated dataflow or a refusal card with a reason code.

      file_type_detect fastq_qc ✓ Validation passed
    4. 4

      Choose output

      Read each step and its reason, then press Select Results Folder and tick I reviewed the workflow and approve running these Skills locally. Nothing runs until you do.

      ✓ I reviewed the workflow and approve running these Skills locally.
    5. 5

      Run locally

      Press Run Workflow. The app validates the plan once more, runs each skill on your computer and shows a step-by-step log. When it finishes, Open Run Report shows what ran and which files it produced.

      Open Run Report

    Writing requests that plan well

    • Name the files and the output you want: "Run FastQC on both mates and give me one MultiQC report."
    • State parameters you care about, such as a length range or a reference genome. Alignment and host removal need a named reference or index; the planner will not pick one for you.
    • Ask for evidence, not verdicts. "Summarise read quality" is a task; "prove these reads are ancient" is a claim the app will refuse.

    WHAT YOU GET

    One folder per run, with the result and its history kept apart.

    The files you asked for sit in final_outputs. Everything that explains how they were made sits next to them, so a colleague or reviewer can check the run without the app or the model.

    step_outputshow you got there
    ResearchAgent Recordsproof it happened

    LIMITS

    What the agent refuses, and what it never does.

    These limits are written into the planning contract before the model is called. A refusal is a result, not an error: the app shows the reason and runs nothing.

    • It does not authenticate ancient DNA or identify contamination sources. That judgement stays with the paleobiologist.
    • It cannot write or run code outside the installed skill modules.
    • It does not install missing software or substitute a reference genome.
    • It does not run anything you have not approved.
    ✕
    unsupported_scientific_claim

    Quality-control output cannot show that reads are ancient or free of contamination.

    ✕
    missing_prerequisite

    A required input is missing, such as aligned data or a named reference genome or index.

    ✕
    file_type_mismatch

    The requested operation does not match the format of the uploaded files.

    ✕
    missing_mate

    The request names a paired-end mate that was not uploaded.

    SKILL MODULES

    67 skills in 7 modules. The plan can use nothing else.

    The module list is fixed before the model is called. Tools that are not bundled with the app must be installed in your environment before their skills can run.
