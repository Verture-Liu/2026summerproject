# Bundled third-party software

The Windows research prototype bundles or builds the following independently licensed tools. Their upstream license files must be copied into this directory during the native Windows staging process.

- FastQC 0.12.1
- MultiQC 1.35
- SeqKit 2.13.0
- SeqTk 1.5-r133
- Samtools 1.23.1
- BWA 0.7.19-r1273
- Bowtie2 2.5.5
- Eclipse Temurin JRE 21.0.8+9 (runtime used by FastQC)

PaleoRigor does not change the licenses of these projects. Source locations, versions and archive checksums are recorded in `../tool-sources.json`.
